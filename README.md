# بوت وتطبيق أرباح كاش (Telegram Cash Bot + Adsgram) 💰

مشروع متكامل لبوت وتطبيق مصغر (Telegram Mini App) يتيح للمستخدمين مشاهدة إعلانات Adsgram بمقابل مالي وسحب أرباحهم على محافظ الكاش المصرية (فودافون كاش - أورنج كاش - اتصالات كاش - وي كاش).

---

## 📱 مميزات التصميم والواجهة (UI/UX):
* **بساطة فائقة (Ultra-Simple)**: واجهة مخصصة تماماً للمستخدم البسيط والبعيد عن التقنية.
* **بدون بهرجة وبدون زوايا منحنية (Zero Border Radius)**: خطوط واضحة، حدود كلاسيكية عالية التباين لسهولة القراءة تحت أي ظرف.
* **أزرار كبيرة ومباشرة**:
  * زر ضخم مباشر لمشاهدة الإعلان وحصد المكافأة.
  * اختيار المحفظة بنقرة واحدة بألوان الشركات المألوفة (أحمر فودافون، برتقالي أورنج، أخضر اتصالات، بنفسجي وي).
* **حماية من الاحتيال (Anti-Cheat & Cooldown)**: فحص أمني لمنع النقر المتكرر أو محاولة إضافة الرصيد دون مشاهدة الإعلان.


## 🚀 طريقة الإعداد والتشغيل:

### 1. ضبط البيانات في ملف `.env`:
افتح ملف `.env` وعدل القيم التالية:
```bash
# 1. توكن البوت من @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# 2. معرف حسابك الشخصي (Telegram User ID) لتصلك طلبات السحب
# احصل عليه من بوت @userinfobot
ADMIN_ID=123456789

# 3. كود الإعلان من منصة Adsgram (Block ID)
ADSGRAM_BLOCK_ID=1234

# 4. المكافأة لكل إعلان بالجنيه (مثال: 0.05 = 5 قروش)
REWARD_PER_AD=0.05

# 5. الحد الأدنى للسحب بالجنيه
MIN_WITHDRAWAL=20.0

# 6. رابط الميني آب (يجب أن يكون HTTPS)
WEB_APP_URL=https://your-domain.com
```

### 2. ضبط زر التطبيق في BotFather:
1. اذهب لبوت **@BotFather** على تليجرام.
2. اكتب الأمر `/mybots` واختر بوتك.
3. اضغط على **Bot Settings** ثم **Menu Button**.
4. اضغط على **Configure menu button**.
5. أرسل رابط موقعك (`https://your-domain.com`) واكتب اسم الزر: `💰 فتح محفظة الأرباح`.

### 3. تشغيل البوت:
لتشغيل البوت والسيرفر محلياً:
```bash
bash /home/kali/telegram_cash_bot/start.sh
```

## 👮‍♂️ لوحة تحكم المسؤول (أنت):
* أرسل الأمر `/admin` للبوت من حسابك المسجل كـ `ADMIN_ID`:
  * يعرض لك إجمالي المستخدمين، عدد الإعلانات المشاهدة، وإجمالي الأرباح.
* **إشعارات السحب الفورية**:
  * عندما يطلب أي مستخدم سحب رصيده، ستصلك رسالة خاصة من البوت تحتوي على:
    * اسم المستخدم ومعرفه.
    * شركة المحفظة (فودافون/أورنج/اتصالات/وي).
    * رقم الهاتف والمبلغ المطلوب.
    * زران: `[ ✅ تم التحويل (تأكيد) ]` أو `[ ❌ رفض وإرجاع الرصيد ]`.
  * بمجرد ضغطك على تأكيد التحويل، يرسل البوت رسالة تهنئة للمستخدم تلقائياً بأن المبلغ وصل لمحفظته.
  * وفي حال الرفض، يعود المبلغ مباشرة إلى رصيد المستخدم مع إشعاره بالتأكد من صحة رقمه.
